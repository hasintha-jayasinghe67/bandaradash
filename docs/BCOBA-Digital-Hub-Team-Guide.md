# BCOBA Digital Hub — Team Guide

**Purpose:** One shared system to plan, approve, adapt, publish, and track official BCOBA digital communications — across campaigns and channels — without buying a full Hootsuite/Metricool subscription.

**App (local):** http://localhost:8787  
**Demo admin:** `admin@bcoba.lk` / `admin123`

---

## 1. What this Hub does

| Stage | What the team does in Hub |
|---|---|
| **Connect** | Save platform credentials (Facebook Page, Instagram, LinkedIn) |
| **Create** | Write a master post (story, caption ideas, notes, tags) |
| **Adapt** | Adjust wording per channel (FB / IG / LinkedIn / WhatsApp / YouTube) |
| **Approve** | Review → request changes → approve |
| **Schedule / Publish** | Schedule for later, or publish now |
| **Engage** | Log comments/DMs and escalate if needed |
| **Track** | See ops status + basic analytics |

It is **BCOBA-wide** (not only Main Hall). Campaigns live under categories (e.g. Projects, Alumni, Sports). Main Hall is Campaign #1 under Projects.

---

## 2. How a post moves (simple flow)

```
Draft  →  Submitted  →  In review  →  Approved
                                      ↓
                              Scheduled  →  Published
```

1. **Compose** a post  
2. Click **Save as draft** (keep working, nothing goes live)  
   **or** **Send to Digital Comms** (enters review queue)  
3. Editor adapts channel packs in **Publisher**  
4. Approver **Approves** / **Schedules** / **Auto-publishes**  
5. Team checks live links + engagement  

**Important:** Saving a draft or submitting for review does **not** post to Facebook/Instagram/etc. Live posting only happens when someone uses **Auto-publish**, **Schedule** (due time), or posts manually outside Hub.

## 3. Channels — what works today

| Channel | In Hub today | How publishing works |
|---|---|---|
| **Facebook Page** | Yes | Auto-post via saved Page connection (tested) |
| **Instagram** | Partial | Needs IG Professional account linked to the FB Page + image; setup pending |
| **LinkedIn** | Partial | Needs LinkedIn app token + person/org URN |
| **WhatsApp** | Manual pack | Copy message from Publisher → paste in WhatsApp Business / Community / Broadcast |
| **YouTube** | Credentials only | Full upload later |
| **Facebook / Instagram Reels** | Not yet | Planned |
| **TikTok** | Not yet | Planned |

### Facebook (ready)
- Connect a **Facebook Page** (not a personal profile) under **Connections**
- Paste Page ID + access token (or user token; Hub resolves Page token)
- Use **Quick post** to test, or **Publisher → Auto-publish**

### WhatsApp (manual by design)
WhatsApp Business app does not offer simple Community/Broadcast auto-post like Facebook. Hub prepares the message; Channel Admin copies and sends.

## 6. Draft vs live (for the team)

| Action | Goes live on social? |
|---|---|
| Save as draft | No |
| Send to Digital Comms | No |
| Approve only | No |
| Schedule (future time) | Yes, when due |
| Auto-publish now | Yes |
| Connections → Quick post (Facebook) | Yes, immediately |

Use **drafts** to prepare content offline from social. Publish only when the team is ready.

## 7. Connections & tokens (ops note)

- Facebook / Instagram use **Meta** (same developer app family)  
- LinkedIn needs a **separate LinkedIn app**  
- Explorer tokens are often short-lived (hours). For ongoing use, exchange to a long-lived Page token  
- Personal Facebook profiles **cannot** be auto-posted; only **Pages**  
- Official PPA Page example: https://www.facebook.com/BandaranayakeCollege.PPA  
  (admin access required before connecting)

## 9. Suggested team operating rhythm

2. Digital Comms reviews in **Queue** twice weekly

4. Channel Admin handles **WhatsApp** copy/send at the scheduled time  
5. Engagement owner checks comments/DMs and logs in **Engagement**
